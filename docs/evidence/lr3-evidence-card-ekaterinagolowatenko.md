## 2. Личный вклад

Мой вклад, представленный в PR #40:

1. Протокол `docs/reproducibility/lr3.md`: окружение, таблица версий
   данных, восстановление v1 и v2, сверка SHA-256, различия между
   Git commit, DVC hash и SHA-256, отказные сценарии и передача
   DVC-хранилища коллеге.
2. Тест `tests/test_dvc_refusal.py`: проверка чистого состояния после
   `dvc add` и обнаружения последующего изменения CSV без `dvc add`.
   Код возврата проверяется через `dvc status --quiet`, а слово
   `modified` — отдельным вызовом обычного `dvc status`.
3. Проверки команд и результатов, зафиксированные в описании PR #40.

В принятом протоколе приведены команды PowerShell и пояснения
по их адаптации для Bash. Тест DVC пропускается, если модуль DVC
недоступен используемому интерпретатору Python.

Правки по ревью подготовил тимлид Станислав; согласно описанию PR #40,
я проверила команды и загрузила исправления.

Командная инициализация DVC и создание версии данных v2
не относятся к моему личному вкладу.
